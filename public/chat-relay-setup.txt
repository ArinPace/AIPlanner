AI Planner — VM-free Chat extension (Chrome / Edge desktop)

1. Download chat-relay-extension.zip from the Chat tab and extract it.
2. Open chrome://extensions (Chrome) or edge://extensions (Edge).
3. Enable Developer mode, choose Load unpacked, and select the extracted folder containing manifest.json.
4. Reload AI Planner and open Chat. Click Open ChatGPT.
5. Sign into ChatGPT in the new tab. Select Work, then return to Planner.
6. Wait for “ChatGPT Work connected on this device,” then send a test message.

Version 0.3.6: Chat has a protected Main Chat, saved conversations, pin/archive/bin,
text branching/editing, incremental history, saved drafts, queued text (Tab),
dictation, paste/drop attachments, Begin Planning (/plan), and live Planner tools
for calendar, Files, shared memory and personal instructions. Internal prompts
and tool traffic are hidden in Planner Chat. Native Pause/Resume/Stop controls
appear only when ChatGPT exposes them. Enter while working forwards a follow-up.
New chat creates/reuses the ChatGPT project Ai Planner.
Use existing tab lists ChatGPT tabs in this browser. Choosing a conversation also
moves it into Ai Planner. Unrelated chats are left alone. Finish any running reply
and send or clear unsent ChatGPT drafts before switching conversations.

To upgrade: replace the extracted files, click Reload on the extension at
chrome://extensions or edge://extensions, then reload Planner and ChatGPT.

The extension controls only the ChatGPT tab you create or explicitly select. It does not use a VM,
read account cookies/tokens, or start the original Agent VM transport.
Keep Planner and the ChatGPT tab open while relaying messages. This prototype does not
provide unattended forwarding after the browser exits or the device sleeps.
Planner tools use your authenticated Planner account; no API key is sent to ChatGPT.
Use Cloud browser / Add site for websites. Enter passwords only in ChatGPT's secure
sign-in form, never in chat. Approvals, MFA and CAPTCHAs may need your attention.
Cloud browser sessions can stay signed in. The original Agent schedule is separate;
no unattended device schedule is enabled. Archive/bin/reset affect this Planner Chat
workspace, not original conversations on chatgpt.com. Branches copy up to 100 text
turns; reattach original files. Queued text is saved for this browser session; files
cannot be queued. Previously saved changes are preserved when stopping a task.
Only laptop Chrome/Edge is packaged here. Phone installation has not been implemented.

Hide ChatGPT moves only the selected relay tab into its own minimized window.
Open ChatGPT restores that window when sign-in or approval is needed. The
browser must remain running; this does not make Chrome extensions work on phones.
Uploads are sent only after ChatGPT displays every prepared attachment. If an
upload fails, the draft stays in ChatGPT for review rather than sending without it.

When ChatGPT pauses for website sign-in, Planner keeps tracking the task. Use
Secure sign-in opens only the connected ChatGPT tab in a dedicated window,
keeping the Planner tab selected in its original window. Sign in through the
genuine ChatGPT form or cloud-browser handoff, select I'm done there if offered,
then use Return to AI Planner. The task window is minimized, not closed.
This is a separate native window, not an iframe inside the Planner website;
ChatGPT's framing restrictions remain intact. Passwords are never forwarded
through Planner. This desktop feature does not implement iPhone sign-in.
File cards in the connected conversation appear as Download buttons in Planner.
These invoke ChatGPT's own download control; private session URLs are not copied.
